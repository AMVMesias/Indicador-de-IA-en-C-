# IBM Project CodeNet

Subconjunto académico de IBM Project CodeNet. Fuente: https://github.com/IBM/Project_CodeNet

Los programas proceden de AIZU Online Judge y AtCoder. Las rutas, identificadores y metadatos permiten reconstruir cada selección.

Datos bajo Community Data License Agreement Permissive 2.0. El texto íntegro acompaña este subconjunto. La licencia de las herramientas del repositorio no sustituye la de los datos.

Referencia: R. Puri et al. Project CodeNet A Large Scale AI for Code Dataset for Learning a Diversity of Coding Tasks. NeurIPS Datasets and Benchmarks, 2021. https://arxiv.org/abs/2105.12655

Etiqueta operacional: HISTORICO_CODENET. La procedencia histórica no certifica autoría humana individual.
